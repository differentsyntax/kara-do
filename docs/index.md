# Kara Do (करा दो)

> 🔒 **This app does not use the internet.** It cannot upload your screen, your data or anything else. You can check it yourself on the Play Store: see *App permissions*.

> 🤝 **Install it only with someone you trust.** Ask a family member or friend who knows phones to set it up with you. If anyone calls or messages asking you to install an app, including this one, do not do it.
>
> 🤝 **किसी भरोसेमंद व्यक्ति के साथ ही install करिए।** अपने घर के किसी सदस्य या जान-पहचान वाले से, जिन्हें phone की जानकारी हो, साथ बैठकर setup करवाइए। अगर कोई अनजान आदमी call या message करके कोई app install करने को कहे, चाहे वो यही app हो, तो बिल्कुल मत करिए।

Step-by-step phone help in Hindi and English for people who didn't grow up with smartphones. It runs privately on the phone, and it points but never takes over.
