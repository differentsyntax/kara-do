# 2026-10-19: Day 1, the first skeleton

**What happened**
- Set up the code: two pure Kotlin modules (`core/recipes`, `core/engine`) and the Android `app`.
- Wrote the first recipe: **make the screen brighter**. It has both modes, "रास्ता सिखाइए" (the full route from the home screen) and "सीधे ले चलिए" (a shortcut straight to the Display settings).
- Built the step engine and matcher. Without any AI, it finds the right button from the screen's labels in English or Hindi. It rings the whole row you need to tap, asks you to scroll when the button is further down, follows you if you skip ahead, and stops in payment apps.
- Tested it on hand-made screens resembling a Pixel, a Samsung and a Xiaomi phone set to Hindi. All 19 tests pass.
- Built the Android side: onboarding (the trusted-helper question, then what Kara Do can see, then turning on the service), a read-only accessibility service, the saffron ring overlay with Repeat / Done / Stop, and Hindi or English voice.
- Added a CI privacy check that fails the build if the app ever asks for internet access or gains a way to tap.

**Setbacks**
- The development machine has no Android SDK, so the app module can only be compiled in GitHub CI for now.
- The test screens are synthetic. Real recordings from family phones are the next most valuable thing.

**Next**
- Get the app building green in CI, then install it on a real phone and try brightness end to end.
- Record real screens from Samsung, vivo, Oppo and Xiaomi phones.
