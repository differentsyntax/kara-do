# 0007: Set up only with a trusted helper
Status: Accepted · 2026-10-19

**Context.** Scammers already persuade older people to install apps and turn on screen-access permissions over the phone. Kara Do needs that same accessibility permission. If an elder learns "it's fine to install an app and allow access when told to", we have made them *less* safe.

**Decision.** Kara Do is designed and promoted to be installed by **someone the person knows and trusts, who knows phones**, sitting with them (or on a video call they started themselves).
- **Website, Play listing and README** all say this up front, in Hindi and English: never install this or any app because a stranger, caller or message asked you to.
- **First-run asks:** "Is someone you know and trust helping you set this up right now?" If the answer is no, the app explains why it matters and suggests waiting for family. It does not refuse to work, but it makes the safer path the obvious one.
- **Setup guide for helpers.** The helper (the son, daughter or friend) gets a short checklist: install from Play only, check the developer name, turn on the permission together, and practise one task.
- **A built-in warning.** "Kara Do will never call you, message you, or ask you to install anything. If someone does, it's a scam." This shows during onboarding and in Help.

**Consequences.** This is slower to spread than a one-tap install, but it teaches the right habit and matches how families actually adopt apps (the adult child installs it). It strengthens the trust story rather than undermining it.
